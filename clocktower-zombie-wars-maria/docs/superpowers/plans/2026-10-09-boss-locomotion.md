# Boss 模型步态与动作衔接

目标：六类 Boss 步态跟随碰撞处理后的实际位移，停住时不原地踏步，收招连续接入行走，并保存到现有 GitHub 仓库的工作分支。

实现：boss-combat.js 保存距离驱动的步态时间、速度权重与各类步幅；game.js 在移动和碰撞完成后更新步态，并在绘制时使用同一个时间源。地面技能继续保持接地。冻结不推进步态，冲锋和扑跃不计入行走步数。
